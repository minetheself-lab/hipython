1. 문서 개요

1.1 목적

본 문서는 전력 피크 경보 & DR 수익 시뮬레이션 플랫폼 구축을 위한 소프트웨어 요구사항을 정의하는 것을 목적으로 한다. 본 시스템은 제조공장의 전력 데이터를 기반으로 피크 발생을 사전에 예측하여 경보를 제공하고, DR(수요반응) 참여 시 예상 수익을 시뮬레이션하여 전력 비용 절감 및 수익 창출을 지원하는 AI 기반 플랫폼이다.

1.2 범위

본 시스템의 범위는 제조공장의 전력 관리 플랫폼으로, 중소기업부터 대기업 제조공장까지 폭넓게 적용 가능하다. 주요 기능으로는 전력 사용량 예측, 실시간 피크 경보, 설비 부하 분산 추천, DR 수익 시뮬레이션이 포함된다. 데이터는 KAMP(인공지능 중소벤처 제조플랫폼)의 실제 공장 데이터를 기반으로 하며, 별도의 하드웨어 설치 없이 CSV 파일 업로드만으로 즉시 분석이 가능한 SaaS 형태의 웹 애플리케이션으로 제공된다.

1.3 용어 정의

용어 정의
피크(Peak) 특정 기간(보통 15분 단위) 동안 측정된 최대 전력 사용량(kW)을 의미한다.
피크연동제 직전 12개월 중 하계(7~9월) 및 동계(12~2월)에 발생한 최고 피크 전력을 기준으로 향후 1년간의 기본요금을 산정하는 제도이다.
DR(Demand Response) 수요반응 제도로, 전력 수급 위기 시 전력거래소의 요청에 따라 전력 사용량을 감축하면 그에 상응하는 보상금을 지급받는 제도이다.
SMP(System Marginal Price) 계통한계가격으로, 전력 시장에서 시간대별로 결정되는 전력 거래 가격을 의미한다.
FEMS Factory Energy Management System의 약자로, 공장 내 에너지 사용 현황을 모니터링하고 제어하는 시스템을 말한다.
kWh / kW kWh는 시간당 전력 사용량(에너지의 양)을, kW는 순간 전력(에너지의 세기)을 의미한다.

2. 시스템 개요

2.1 시스템 목적

본 시스템은 예측 불가능한 전력 피크로 인한 과도한 기본요금 지출 문제를 해결하고, 복잡한 DR 정산 과정을 자동화하여 제조기업의 전력 비용 최적화를 달성하는 것을 목표로 한다.

2.2 시스템 컨텍스트

  • 외부 시스템: KAMP 데이터셋(입력 데이터), KEPCO 전기요금 체계(계산 로직)
  • 사용자:
    • 중소기업 전기 담당자 (실무 운영)
    • 중소 공장 대표 (의사결정)
    • 대기업 에너지 관리팀 (통합 관리)
  • 출력: 향후 전력 예측 그래프, 피크 위험 경보, 설비 제어 추천, DR 수익 리포트

2.3 기술 스택

구분 상세 기술
프로그래밍 언어 Python 3.8+
데이터 처리 pandas, NumPy
AI/ML 모델링 XGBoost, Random Forest, DNN (Scikit-learn, TensorFlow/PyTorch)
최적화 알고리즘 Google OR-Tools
웹 프레임워크 Streamlit
시각화 Plotly

4. 기능 요구사항 (Functional Requirements)

4.1 전력 사용량 예측 (Power Usage Prediction)

ID 기능명 설명 우선순위 수용기준
FR-001 시간별 전력 사용량 예측 기온, 생산량, 시간대, 요일, 공장인원, 전기요금 구간을 입력받아 향후 1~4시간의 전력 사용량을 예측한다. Must Have MAPE ≤ 5%
예측 응답시간 ≤ 3초
FR-002 다중 모델 비교 Random Forest, XGBoost, DNN 3가지 모델의 성능을 비교하고 최적의 모델을 자동으로 선택한다. Must Have RMSE, MAE, MAPE 지표 제공
FR-003 예측 결과 시각화 시간대별 예측 전력량을 Plotly 라이브러리를 사용하여 직관적인 그래프로 표시한다. Should Have 1~4시간 예측 곡선 표시

4.2 피크 경보 시스템 (Peak Alert System)

ID 기능명 설명 우선순위 수용기준
FR-004 3단계 피크 경보 계약전력 대비 사용량을 분석하여 3단계 경보를 발령한다.
- 주의: 80%
- 위험: 90%
- 초과임박: 95% 		Must Have 피크 도달 30분~1시간 전 경보 발송 성공률 95% 이상
FR-005 절감액 자동 계산 피크 감축 성공 시 예상되는 월간 및 연간 전기요금 절감액을 KEPCO 요금 기준에 맞춰 자동 계산한다. Must Have 기본요금 산정 공식 정확도 100%
FR-006 실시간 알림 경보 조건 발생 시 대시보드 상단에 팝업 알림을 즉시 표시한다. Should Have 경보 발생 후 5초 이내 알림 표시

4.3 설비 부하 분산 추천 (Equipment Load Balancing)

ID 기능명 설명 우선순위 수용기준
FR-007 설비 가동 순서 최적화 OR-Tools를 활용하여 전기요금을 최소화할 수 있는 설비 가동 시간 및 순서를 추천한다. Should Have 생산 목표 유지하며 피크 10% 이상 절감 스케줄 제시
FR-008 설비 ON/OFF 추천 피크 임박 시 "지금 A설비를 끄면 피크가 X% 낮아집니다" 형태의 구체적인 행동 가이드를 제공한다. Must Have 권고 수용 시 실제 피크 5% 이상 감소

4.4 DR 수익 시뮬레이터 (DR Revenue Simulator)

ID 기능명 설명 우선순위 수용기준
FR-009 DR 수익 계산 사용자가 입력한 감축량(kWh)에 따라 예상되는 DR 보상금을 자동으로 계산한다. Should Have 보상금 계산 공식 정확도 100%
FR-010 1회/월/연 수익 예상 DR 1회 참여 시 수익뿐만 아니라 월 15회 참여 가정 시, 연간 누적 예상 수익을 계산하여 표시한다. Should Have 기간별 수익 추정값 표시
FR-011 SMP 연동 (로드맵) 전력거래소 SMP API를 연동하여 실시간 시장 가격을 반영한 정교한 수익 계산을 제공한다. Nice to Have Phase 2에서 구현

4.5 데이터 관리 (Data Management)

ID 기능명 설명 우선순위 수용기준

6.2 출력 데이터 (Output Data)

  • 예측 전력량: float (kWh) - 향후 1~4시간 예측값
  • 피크 위험도: string - "80% 주의 / 90% 위험 / 95% 초과"
  • 절감 예상액: int (원) - 월간/연간 절감 가능 금액
  • DR 수익 예상: int (원) - 1회/월/연 DR 참여 시 수익
  • 추천 설비 목록: list - "에어컨 2대, 컴프레서 1대" 등

7. 시스템 제약사항

  • 데이터 제약: KAMP 데이터셋 형식(18개 컬럼, 15분 단위)을 준수해야 함.
  • 기술 제약: Python 3.8 이상, Streamlit 1.0 이상 환경에서 구동되어야 함.
  • 하드웨어 제약: 최소 사양으로 CPU 4코어, RAM 8GB 이상 권장 (GPU 불필요).
  • 시간 제약: 실시간 센서 데이터 연동이 불가하므로 CSV 기반 배치 처리 방식을 따름.
  • 비용 제약: 유료 API 사용이 불가하며, SMP 연동 등 비용 발생 기능은 Phase 2로 미룸.
